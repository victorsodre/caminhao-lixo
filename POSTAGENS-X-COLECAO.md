# Postagens do X — coleção de experiências do ovictorlab

**Rascunhos para publicação manual posterior. Nenhuma postagem foi enviada.**

Este arquivo reúne a coleção e ficará no repositório piloto `caminhao-lixo`. Cada projeto mantém seus textos em `POSTAGENS-X.md`; ao editar um texto individual, atualizar também esta compilação.

## Ordem de uso

1. Apresentação da coleção, quando Victor quiser anunciar a intenção.
2. Planejamento de um projeto por vez, seguindo a prioridade.
3. Bastidor apenas após existir o protótipo descrito e uma captura real.
4. Lançamento apenas após a URL pública funcionar e os controles prometidos estarem validados.

Não anunciar os dez como prontos. Não publicar os blocos de condição/mídia junto do texto. Links privados do GitHub não são links de demonstração pública. Os textos foram mantidos curtos; revisar no compositor do X antes de publicar.

## Apresentação da coleção — pode ser usada como anúncio de intenção

```text
O Fusquinha abriu uma ideia: transformar os assuntos do ovictorlab em experiências que você pode explorar. Organizei dez projetos, de um caminhão de lixo à Voyager. O primeiro passo é abrir o caminhão por dentro e deixar você controlar o mecanismo.
```

Mídia: captura real do Fusquinha, identificada como referência; não apresentar render de projeto futuro como produto pronto. Resposta opcional: link para o Fusquinha já publicado.
